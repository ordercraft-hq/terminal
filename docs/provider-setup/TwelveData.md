# Twelve Data Provider Setup Guide

This guide walks you through configuring **Twelve Data** multi-asset market data (Equities, Forex, Crypto, Indices, ETFs) in **ORDERCRAFT**.

---

## Getting Your Twelve Data API Key

1. Register for a free account at [Twelve Data](https://twelvedata.com/).
2. Navigate to your [API Key Dashboard](https://twelvedata.com/account/api-keys).
3. Copy your API key (e.g. `8a7b9c6d...`).

---

## Configuring in ORDERCRAFT

1. Open the **Data Providers & Feeds** panel from the right dock rail.
2. Under **Supported Integrations**, click **Configure** next to **Twelve Data**.
3. Fill in:
   - **Account ID**: (Optional) Plan or Account ID
   - **API Key / Token**: Your Twelve Data API Key
   - **Secret**: (Optional)
4. Click **Save Credential**.
